# Local syntax admission accounting

The bounded per-position syntax footprint is implemented and independently
reviewed at the five identities in `source-hashes.json`. The fixed standard
meta-schema validators still inspect the complete original value. Only the
object/Boolean child tokens whose localized edges perform a kind check are
excluded from the parent reservation, with a positive per-child unit. Header
scans are separately charged. Names, string arrays, exact operands, opaque data
and wrong kinds retain their extents. The 64 multiplier, fixed overhead and cold
compiler allowance remain unchanged. No cross-phase syntax cache is added.

The complete normalized localized-resource graph and selected root are pinned
in a checked-in guard snapshot. Actual snapshots use the production localization
and root-selection functions. Independent review found the initial missing root
selection guard; the corrected test detects reordered resources selecting a
core-only meta rather than the complete dialect root. The snapshot is reviewed
input, not automatically updated by tests. Pinned publication bytes remain
separately checked by the existing input gates.

`results.json` distinguishes broad native current/minimum-toolchain runs before
the final private root-helper extraction from final focused guard/lint checks,
final-source independent replays, and final rebuilt Wasm/Node/browser/package
checks. The broad native runs passed 540/539 tests with the established stack
policy; both replayed all 1,546 required values. All nine final guard groups pass
on both compilers. Independent final-source review passes 210 bounded controls,
585 cancellation boundaries, 63 nested ignored-failure groups, three cold/warm
processes, all 1,546 direct-original-Plan values and 62 public numeric/frozen
workloads. Actual Node passes 180; each browser passes 505 core and 1,546 evaluator
cases. The final installed npm archive checks pass 352 assertions. Inventories
overlap and are not additive semantic coverage.

Initial harness failures are retained: the first formatting command preceded the
new test module file; an installed-package attempt could not write npm's cache.
Finishing the test source and rerunning with cache access resolve those issues
without changing expectations or limits. All three final-source release stack checks pass; their log is retained. No full SDK, compiler replacement, matched performance
or all-platform CI completion is claimed.

Remaining engine work includes cross-phase syntax facts, full pattern-program
preparation, explicit evaluation frames, original diagnostic witnesses, the
default-engine switch and outgoing compiler removal. Final performance, hosts
and spec-to-code map review remain open. No old API compatibility is required.
