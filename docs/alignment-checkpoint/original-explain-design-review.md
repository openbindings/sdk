## Concrete finding and accepted refinement

**R-EW1 — final pointer length is not a construction allocation bound.** `backend::location_pointer_size` measures the final retained representation. In `raw.rs:695`, the exact unpaired-name fallback also creates an ancestor `Vec<Vec<u16>>`, decodes every segment, grows that vector and allocates the final pointer. A 128-segment path containing one lone surrogate and otherwise empty names retains 258 bytes but independently requests **6,443 bytes** during `relative_pointer`; depths 8/32/64 request 323/1,547/3,179 bytes for 18/66/130 retained bytes. All allocations release on drop. Thus even a 16× final-length term alone does not certify this helper. The probe, build command and unchanged observations are retained beside this report.

Accepted correction: a diagnostic `State` may hold an `Option<Arc<WitnessSeed>>` containing the original schema node, static keyword discriminator and actual instance occurrence. Materialize only the seed selected by the final root false proof. Charge the Arc layout before creation; use the actual State/frame layout in storage reservations. A seed is temporary to the run, owns no control and never enters `Plan`. The call retains the instance arena, and the Plan retains the original schema environment. Resolve the seed through that exact arena rather than equal-value interning. Alternatively an owned-pointer witness is sound if its entire temporary construction is audited, but it eagerly pays for rejected branches and is less economical.

Before calling the existing pointer helper, reserve all segment-vector growth, decoded-name buffers, numeric index text, final pointer and subsequent copies. A direct exact relative-pointer writer with a measured size/cursor is also acceptable. Do not quietly treat the existing final-length measurement as such a certificate. The schema origin needs its own original-source/URI reservation. Reject oversized origins without changing the established failure. The relative root must actually be an ancestor in the same arena: the helper's ancestor walk can panic otherwise. Property-name tokens must never reach this path as if they were ordinary instance values.

## Required propagation invariants

1. At every completed State boundary, a present witness implies `valid == FALSE`; its cause is sufficient for that State's false result under its established guards. Witness metadata never changes formulas, effect identity, cut independence, retry progress, support bounds or annotations. `State::copied` may Arc-clone a seed, with the ordinary storage/work charge; it must not materialize pointers.
2. Unconditional conjunction/reference/property/item/dependent-schema application may forward a concretely false child's witness. OR, NOT and conditional continuations must explicitly choose or clear it. A false alternative of a successful `anyOf`, the failed condition of `if`, or an inactive `then`/`else` must not escape as a root cause. A whole false `anyOf`/`oneOf` can cite its own applicator; a correlated contradiction without a reportable concrete witness may remain empty and incomplete.
3. `patternProperties` forwards a child only when matching is TRUE. Additional/unevaluated property or item application forwards only when its applicability guard is TRUE. The current interpreter evaluates guarded children eagerly; encountering a false child is not itself evidence that the child applies. `contains` failure belongs to the cardinality applicator, not a nonmatching item. `propertyNames` reports the parent object and its own keyword.
4. Completed memo keys remain original schema + **actual instance occurrence** + effective scope. Equal-value effect interning must never merge locations. Active cuts/opaque summaries start without witnesses. Partial coordinate facts and support summaries do not manufacture or transport diagnostic proof. A retained complete independent false memo may keep its witness across retries; annotation-only refinements cannot supply one.
5. Primitive evaluation still executes the existing ordered checks. Recording the first failed primitive must not short-circuit later control/resource errors. Boolean false uses its real Boolean schema origin; do not invent a `/false` keyword. Arbitrary child-pointer suffixes, projected locations and guessed missing-resource origins remain prohibited.

## Budget and lifecycle requirements

Extract remaining work and requested-allocation counters only after the first run has completed its verdict. Drop the first run's temporary owners, but refund neither work nor cumulative requested storage. The second Graph has only the remainder and the same external control and enclosing preparation Attempt. It retains the existing independent stack/variable/capability bounds. Charge second-run startup, Arc seeds, map/frame storage, pointer construction, final problem/message/vector and ownership copies to that remainder. A successful first failure remains the fallback result when the second pass cannot proceed.

Use an explicit verdict-established boundary. Cancellation before it is NoVerdict; cancellation afterward leaves Fails with incomplete problems. A healthy, adequately funded diagnostic run unexpectedly returning S/U rather than F is a test failure indicating semantic divergence, even though the public fallback must not publish speculative detail. No second run occurs for S/U/N. Outcome means zero witness allocation, not zero ordinary interpreter allocation.

The fixed finite message/code table is appropriate. No instance values, authored pattern text, property names or native engine errors enter messages/debug. Original schema/instance coordinates may necessarily contain authored names; test them as exact coordinates, not by asserting that every serialized diagnostic byte is free of names. Optional detail facts may be absent in this increment; reusing the outgoing helper requires a separate allocation/provenance audit. Keep `problems_complete = false` for this one-witness scope.
