# Once-prepared Program ownership: independent design review

Disposition: approve the proposed private ownership/API direction for implementation, subject to the explicit conditions and 36 frozen controls in `controls.json`. This is not an implementation, default-workload or activation PASS. The completed inactive stage and aggregate receipts remain separately pinned.

Construction should own one immutable Limits policy, structural Budget and temporary normalized-program index. Root and every selected-meta/secondary Plan borrow this owner. A Plan owns only original occurrence-to-Arc<Program> bindings and its existing original environment; Program owns immutable interpretation/matcher data; Search owns per-call mutable cache. Remove the old per-value parsing/compilation/retry route rather than leaving a silent fallback. Missing prepared occurrence is an implementation failure, not permission to compile during evaluation.

## Required seam conditions

1. Reuse only a completed normalized reading under the fixed Construction policy. Source extent, authored depth and pre-Reader expansion admission run for every original spelling before lookup, including cache hits. A source/depth/expanded-form refusal with no complete key never enters the normalized index under a partial spelling. Deterministic local compiler refusals can be indexed after full normalization; shared SDK, aggregate and cancellation failures cannot. Every actual backend construction spends its admitted phases; an actual reused immutable owner does not manufacture another construction debit.
2. Arc equality is storage equality only. Preserve original arena/node operand identity, keyword/name provenance and semantic subject/effect identity. The approved semantic design explicitly keeps distinct authored defect sites separate even when their text matches. PP-04 requires Undefined for two distinct invalid-pattern sites combined as P and not Q; PP-05 requires Fails when both paths reference the same original invalid predicate P. Equivalent Programs must not merge those cases. Pattern values and patternProperties names may share code while retaining distinct occurrence bindings and diagnostics.
3. Define total_pattern_memory as a named accounted retained footprint. The locked NFA memory_usage API sums representation lengths, not Vec capacities or allocator requests, and omits Arc bookkeeping. Program/Arc owner layout and Simple backing need separate explicit terms; the documentation must not call the result exact total allocated bytes. If additional known headers are counted, name them. Keep actual allocator peak/request/time gates, especially near the aggregate ceiling with earlier programs still retained. Search caches are separate per-call storage, not an invented fixed share of Program memory.
4. Move the Simple matcher out of the temporary Reading and move one complete normalized String into the index on a miss. Program must not accidentally retain Arc<Reading> and therefore normalized text. On a hit, drop the newly read temporary form/Simple data before final completion checking. Scope RefCell map borrows to lookup/insert, outside dependency construction and control callbacks. Reserve/index work before retention and use checked aggregate extent/footprint addition. The source-form extent is now unique indexed normalized extent across the Construction, including names; explicitly retire the old per-Plan/name-counting policy tests.
5. Limited is a typed local terminal limitation, never Undefined or an uncertainty atom. “Demanded” means actual interpreter reach, as already adjudicated; this design adds no promise to skip every mathematically decisive anyOf/if branch. Nonstring pattern values and empty/nonobject patternProperties values do not request a match. A selected meta-schema that actually demands Limited cannot admit its consumer. Invalid syntax and valid unsupported features retain their distinct interpretation and correlation.
6. Program retains a checked match-work bound computed once from the completed state/edge representation (or Simple form/matcher bound). Search allocates VM cache lazily only on the relevant match path and uses the reviewed union-edge-aware cache bound. Preserve existing exact UTF-16 handling and variant precedence; unpaired source/text must not become lossy UTF-8 cache keys or invent successful matching. Concurrent calls never share mutable cache/control.
7. Successful Program ownership publication is transactional with respect to aggregate failure/cancellation. Check shared state before returning a hit and before publishing a miss, after temporary cleanup. A final failure destroys the partial Construction/index/Plans; no process-global cache survives. The existing outer Attempt cancellation precedence stays explicit. Distinct outer attempts start fresh; inner meta/secondary Plans never do.

The design author has accepted the key footprint, complete-key, immutable-policy and actual-demand conditions. No blocker requiring Matthew remains. The BTreeMap choice is coherent for a temporary ordered index, provided its key/comparison/storage work has an explicit bounded SDK policy; it does not require reopening the retired full dependency instruction/allocator certificate.

## Gate order

Implement the private owners and occurrence seam, then qualify once-only entry counts, original-effect controls, local-vs-shared failures and actual root/meta aggregate behavior. Follow with retained-footprint exact/one-below and cleanup/concurrency controls. Replay frozen default jobs and adversarial transient/stack/time measurements with all programs retained, not immediately dropped after each compile. Force the original engine through required/auxiliary/consumer/Explain tests and actual hosts so the outgoing backend cannot hide missing coverage. Only then switch default/delete the outgoing engine and retired limits/docs, followed by the clean package and full alignment gates.

Existing stage evidence and normalized semantic controls are reused. Full pattern-program-once, end-to-end meta debit and final resources remain open until these gates execute.
