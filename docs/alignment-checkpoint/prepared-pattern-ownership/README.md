# Once-prepared pattern programs

Original-node preparation now creates immutable Program owners once and shares
completed normalized forms across values, names, resources and selected meta-schema
Plans. Original occurrences retain their independent effects and locations. Simple
matchers move directly out of the Reader; other supported forms use the reviewed
single-build factory. Value calls allocate their own search caches and never parse
or compile a pattern. Program and Plan retain no construction Control or index.

One Construction fixes its evaluator policy and owns the shared temporary index,
structural Budget and defined retained footprint. No RefCell guard crosses a Reader,
compiler or Control call. Source/depth checks still precede normalized reuse. Local
limits are terminal only when reached; shared exhaustion aborts preparation. A
charged temporary key permits rollback after late index-allocation cancellation.
The footprint explicitly counts program owners, Simple backing and NFA representation
lengths; it is not allocator capacity, temporary dependency storage or process RSS.

[Independent implementation review](independent-review.md) passes with no open
production finding in this seam. It adds 16 ownership/resource groups on each Rust
version, 94 observed miss/hit cancellation boundaries, original-location/correlation
controls, and 62 preserved numeric/large jobs. A lowered aggregate-footprint probe
keeps three programs live while refusing a fourth, measures the candidate's
transient peak separately, and releases all owners. That probe is not a claim to
have reached the hard 64 MiB upper ceiling. Full performance/default gates remain
separate from this bounded review.
