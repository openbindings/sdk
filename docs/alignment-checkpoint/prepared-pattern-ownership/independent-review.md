Programs contain immutable matcher/interpretation data only. Plans retain original occurrence bindings and environment ownership. The initial normalized String clone is now an explicit reviewed refinement: its reservation supports transactional rollback on late cancellation, only one index String survives, and neither Program nor Plan retains it. Source/depth/Reader admission still precede cache lookup. Partial readings and shared failures never enter the normalized index. Shared extent/footprint refusals are sticky; final Construction checks run on success and error paths.

The BTree index uses a conservative height bound (`floor(log2(n+1))+2`) above its minimum-fanout height. Twelve key comparisons per level and 1,024 bytes per possible split/root level cover the bounded SDK-owned index operations on the supported 32/64-bit layouts (String/Arc node payload remains below that node allowance). This is a scoped cooperative reservation, not a revived full dependency operation/allocator certificate.
