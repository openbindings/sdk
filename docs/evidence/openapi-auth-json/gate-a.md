# Gate A contract freeze

The existing named credential JSON context plus one kind-specific security point is selected. A Rust-only typed host credential/grant seam would duplicate the adopted role credential carrier and require another bridging design for local Wasm. The shared JSON path keeps source-only authoring and existing invokers unchanged. The application owns its context and must authorize grants independently of source/challenge assertions.

Selection is a set of declared names: unlike an index it survives reordered alternatives. Duplicate equivalent alternatives coalesce; anonymous is the empty set. Missing destination precedes auth challenges, avoiding a server/security cross product. Unsupported alternatives exclude the whole operation initially. Source-only synthesis records nonsecret OR/AND prerequisites. Existing private labels and client pin remain unchanged. These are adapter policies, not future specification mandates.

Admission: authenticated profiles and explicit anonymous choices within those profiles admit the complete encoded context up to Options.context_bytes (64KiB default), reject duplicate names in that admitted context, and bound traversal by those admitted bytes. Already-unsecured profiles ignore auth context, preserving existing behavior. Public metadata is charged to result_bytes. Client document/nodes/descriptor_work/reference_steps bound source and request work; headers bounds header count. Provider challenges use a checked incremental result_bytes serialization before SDK max_error_bytes admission. No whole-RSS or zeroization claim.

Fresh manual OBI/source variants and six literal wire exchanges were authored before runtime edits. Cases.json fixes caller outcomes for every negative variation. Reference fixture selects entry-document implicit names, one upstream-permitted resolution policy; this is explicitly an implementation choice where Appendix F allows variation. No old binding draft or derived expectations were read.
