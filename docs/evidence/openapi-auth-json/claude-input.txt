# Authenticated JSON operations: bounded adapter slice

Status: designed on 2026-10-13; implementation and runtime qualification have not
started. Start from SDK `abc96027691187ad11fe0394f1d1c9d73482e093` on a new branch
`codex/sdk-openapi-auth-json`. Keep the independent client pinned to
`fe09522a9b99a6c6b4918e3de0467b5a638afa5e`. The previous slice remains closed.

The deliverable is one optional OpenAPI provider that can inspect, synthesize,
save/reload, and invoke a finite secured JSON operation through the existing
binding and operation invokers. Applications supply credentials for each attempt.
A developer should not need a separate authentication invoker or a new SDK role.

This document sets engineering acceptance criteria for this implementation. It is
not a binding specification or an expansion of the published role interfaces.
The concrete context design below is a proposed private experiment; Gate A freezes
it against independent consumer examples before product edits begin.

## Authority and exclusions

Use only the exact allowed inputs in [baseline.json](baseline.json): OpenBindings
core, the adopted role definitions, the pinned current SDK/client, applicable
upstream OpenAPI/HTTP rules, and the consumer needs in this plan. Implementation
facts do not become semantic authority. In particular, do not treat the client's
selection indexes, current errors, or internal resolution/cache APIs as requirements
for a binding kind.

**Do not read, quote, use as a comparator, or derive expected results from any old
OpenAPI binding draft or its derivative plans, fixtures, semantic decisions or
review conclusions.** Follow no links into those materials. Current fresh private
experiment behavior is a compatibility baseline, not a normative binding draft.
Reviewers receive this allowlist and fresh cases, not whole-repository research tasks.

Applicable upstream rules are linked in the baseline. Security requirements can
combine schemes and offer alternatives; operation declarations can replace global
security, including anonymous access. These meanings come from the source version,
not this adapter's preferred selection procedure.

## Scope

| In this slice | Outside this slice |
| --- | --- |
| Existing private 3.0 and 3.1 kinds; primary fixtures 3.0.4 and 3.1.2 | Another version family or full-version conformance claims |
| HTTP bearer and API keys in declared headers | Basic, OAuth2/OIDC schemes, mTLS, API keys in query/cookies |
| Already obtained, per-attempt credential strings | Login, issuance, refresh, verification of token claims/roles, a credential broker/store |
| Required combinations and alternatives of supported schemes; anonymous alternatives and operation overrides | Dropping unsupported alternatives silently, choosing from credential availability, authentication negotiation/retry |
| Existing GET/POST scalar path/query and finite JSON profile | New methods, parameter/media forms, streaming or schema translation |
| Manual and synthesized documents, cold reload with supplied resources | Automatic resource acquisition or embedding a full resource graph |
| Rust plus the existing exact-text local Node/Wasm seam | Published TypeScript adapter package, browser/Worker networking or CORS qualification |
| Targeted auth costs, bounds, cleanup and unaffected-path regression checks | Multi-source cache redesign, general allocator/browser-memory qualification |

Only empty scope/role arrays are admitted for these two mechanisms initially.
Nonempty role arrays in 3.1 are an implementation limitation, not invalid OpenAPI;
3.0's non-OAuth scope constraints are evaluated under its own upstream rules.
`bearerFormat` remains descriptive; it is not permission to decode or validate JWTs.
Unsupported mechanisms remain known unsupported targets with no generated callable
operation. Initially an operation with any unsupported effective alternative is
unsupported as a whole. That conservative policy avoids presenting a narrowed set
as full support. Unrelated supported operations remain usable.

## Responsibility boundaries

- **Core and generic roles:** unchanged document model, framing, context forwarding,
  challenge shape, lifecycle and terminal meanings. No OpenAPI-specific credential
  lookup, token store or source acquisition enters these crates.
- **Adapter:** supported-profile analysis; private selection/context mapping;
  conversion of selected caller credentials to client inputs; honest synthesis
  coverage and actionable challenges. No independent HTTP auth encoder.
- **OpenAPI client:** effective source declarations, references and source-version
  interpretation; request preparation, header application, collisions and final
  request-origin checks using explicitly supplied credential scopes.
- **Application/host:** credential acquisition, trust and release decisions, transport
  policy/TLS, storage and logging. A source declaration or challenge never grants
  authority to release a credential. Custom hosts remain trusted application code.

The client already exposes `SecurityAlternative`, `SecurityRequirement`,
`SecurityScheme`, `Input.credentials`, `Credential.origins`, and `Selection.security`.
These are capabilities to reuse, not proof that every needed behavior is qualified.
If a client defect blocks a required case, preserve a minimal reproducer and record
an explicit client dependency. Do not copy client logic into the adapter or silently
change the pin. Unrelated cases can continue; the slice cannot be called complete.

## Proposed consumer contract

The role already defines `context.credentials[name]` as a string for named
`auth.bearer` and `auth.apiKey` requirements. Use that as the documented primary path.
The operation input remains exactly the current parameters/body envelope.
Credentials never become operation-input fields or authored source/binding content.

The initial experiment adds one private configuration point per kind:
`local.openapi-json-probe.r1.security` and
`local.openapi30-json-probe.r1.security`. Its value contains:

- `schemes`: the exact set of declared scheme names selecting one effective security
  alternative, represented as a duplicate-free string array; order is immaterial.
  `[]` selects an explicitly available anonymous alternative. It is optional when
  there is only one distinct alternative. Identical duplicate alternatives may map
  to the same semantic choice. A selector is not a client array index.
- `origins`: a map from each selected scheme name to caller-approved origin URLs.
  The client compares scheme, host and effective port canonically. Scope is checked
  against the actual request destination, not the document's retrieval URI.
  Never populate grants automatically from a source, challenge or selected server.

See the candidate [context](examples/context.json),
[missing-credential challenge](examples/missing-credential-challenge.json), and
[alternative-selection challenge](examples/alternative-selection-challenge.json).
All strings called credentials in these files are manufactured test sentinels.
These examples are proposals, not claims about a currently implemented API.

Use the existing role's convenience forms only as compatibility inputs:
`bearerToken`, `apiKey`, and `apiKeys[name]`. A flat form can resolve only one
unambiguous selected requirement of its family. Conflicting applicable named,
legacy or flat values refuse; equal values may coalesce. No precedence rule may
silently choose between different secrets. Do not add new convenience spellings.
Unused credentials are not forwarded or used to select an alternative. Existing
unsecured operations continue to omit authentication even if context contains keys.

The private `origins` map is the proposed portable JSON seam for this adapter's
release-scope policy, chosen so Rust and a future TypeScript API can share one
context path. Gate A compares it with a typed host-owned grant seam using the same
consumer needs, then records one choice. Do not implement both to avoid deciding.
If a future binding specification adopts a configuration point, that point's
observable meaning would need definition; adopting this grant mechanism at all
is not presumed. No origin-policy algorithm is added to a generic interface.

### Selection and challenge behavior

There is no first-alternative, available-credential, or failure-driven selection.
A single distinct alternative may be used without a selector. Multiple alternatives,
including anonymous versus authenticated, require an explicit semantic selection.
A valid selected combination applies all its requirements together. No fallback to
another alternative is attempted on failure. Origins do not select security schemes.

Server selection retains its current point and behavior. If destination choice is
missing, challenge for it before asking the application to release credentials;
then a fresh attempt can challenge for security choice, missing credentials or
missing grants. Avoid a destination-by-security Cartesian-product challenge.
For an authenticated branch, use the existing `auth.bearer`/`auth.apiKey` requirement
families with source-declared names. Use `config.value` for private selector/grant
values; RFC 6901 paths address within that point. Selection schemas describe sets
without imposing array order. Grant requirements identify the selected origin in
nonsecret explanatory metadata/examples, without treating that assertion as permission. An anonymous selection branch
still has its nonempty selector requirement, satisfying the adopted role shape.

Challenges describe the context still needed for a particular attempt. They never
include supplied secret values, store credentials, spend approval, start a host,
resume the same completed attempt or promise that other caller inputs are valid.
Do not invent a global malformed-input/error precedence rule for the interfaces.
The challenge target remains an untrusted scope assertion; include the relevant
kind, operation, destination and public security requirements, without secret data.
Exact encoding/digest strategy is an implementation choice, not a persistence contract.

Well-formed absent context can produce `CONTEXT_REQUIRED`. Malformed credentials,
conflicts, an invalid selector, an explicit grant for the wrong origin, unsupported
profiles or exhausted admission budgets refuse with no dispatch. Do not ask for a
broader grant when the caller has explicitly supplied a nonmatching one. Supplying
corrected context means starting a deliberate new invocation. After host entry,
401/403 use the existing kind-specific status failure; never turn them into a
no-effect challenge or silently refresh/retry. Existing cancellation/drop semantics
and the distinction between output and terminal success remain unchanged.

No specific preflight implementation is required in this slice. The existing
advisory default remains valid and must not be documented as auth readiness proof.

## Inspection and synthesis

Inspection remains source-only; it never needs credential material. A supported
secured target receives the same sound mechanical operation framing as an
unsecured target. Missing runtime credentials are not implementation-unsupported.

Synthesis preserves the supplied source and the existing path/method binding
locator, leaves credentials out of the OBI, and describes runtime prerequisites
using existing coverage fields. A flat list must not misrepresent OR branches as
one AND; use nonsecret structured coverage details when that distinction matters.
That detail is explanatory output, not a second source of invocation authority.
Do not add auth schema properties to the operation's ordinary input contract.
Runtime prerequisites do not by themselves imply schema loss; preexisting schema
projection loss continues to be reported independently.

A cold reloaded document, independently supplied resources, a new provider and new
per-attempt credentials must reproduce the manual consumer's wire exchanges.
Generated operation keys must remain freely renameable without changing selection.
No credential value or caller-supplied grant is stored in the prepared-source cache.
A caller deliberately resupplying context on a later call is new caller input,
not a cache-isolation violation. No cross-source authorization or cryptographic
identity guarantee is inferred from a shared scheme name or an opaque target string.

//! Private experiment policy. Source interpretation and HTTP encoding stay in the client.
use crate::{Kind, Options, analysis::Profile, json};
use dynamic_openapi_client::{Credential, CredentialValue, Input};
use openbindings::{JsonRef, JsonValue, WorkControl};
use openbindings_invocation::{ContextChallenge, InvocationError};
use serde_json_compat::{Value, json as j};
use std::collections::{BTreeMap, BTreeSet};

#[derive(Clone, Copy, PartialEq, Eq)]
pub(crate) enum Family {
    Bearer,
    Key,
}
impl Family {
    fn requirement(self) -> &'static str {
        match self {
            Self::Bearer => "auth.bearer",
            Self::Key => "auth.apiKey",
        }
    }
}
pub(crate) type Alternative = BTreeMap<String, Family>;

pub(crate) fn details(profile: &Profile) -> Value {
    j!({"alternatives":profile.security.iter().map(|a|a.iter().map(|(n,f)|j!({"type":f.requirement(),"name":n})).collect::<Vec<_>>()).collect::<Vec<_>>()})
}

/// Only applicable context is admitted. Unsecured operations keep ignoring auth context.
pub(crate) fn apply(
    profile: &Profile,
    kind: Kind,
    context: Option<&JsonValue>,
    destination: &str,
    operation: (&str, &str),
    options: &Options,
    work: &WorkControl,
    input: &mut Input,
) -> Result<(), InvocationError> {
    let fail = InvocationError::refused;
    if !profile.security.iter().any(|a| !a.is_empty()) {
        input.selection.security = (!profile.security.is_empty()).then_some(0);
        return Ok(());
    }
    if let Some(c) = context {
        if c.bytes().len() > options.context_bytes
            || c.view().members().is_none()
            || c.has_duplicate_names()
        {
            return Err(fail());
        }
    }
    let root = context.map(JsonValue::view);
    let configuration = member_object(root, "configuration")?;
    let point = member_object(configuration, kind.security_point())?;
    if let Some(p) = point {
        crate::analysis::object(p, &["schemes", "origins"]).map_err(|_| fail())?;
    }
    let origin = dynamic_openapi_client::uri::origin(destination).map_err(|_| fail())?;
    let choices: BTreeMap<Vec<&str>, usize> = profile
        .security
        .iter()
        .enumerate()
        .rev()
        .map(|(i, a)| (a.keys().map(String::as_str).collect(), i))
        .collect();
    let selected = if let Some(s) = point.and_then(|p| p.get("schemes")) {
        let mut names = BTreeSet::new();
        for v in s.elements().ok_or_else(fail)? {
            if work.is_cancelled() {
                return Err(InvocationError::cancelled());
            }
            if !names.insert(v.as_str().ok_or_else(fail)?) {
                return Err(fail());
            }
        }
        Some(
            *choices
                .get(&names.into_iter().collect::<Vec<_>>())
                .ok_or_else(fail)?,
        )
    } else if choices.len() == 1 {
        choices.values().next().copied()
    } else {
        None
    };
    let target = j!([
        kind.label(),
        operation.0,
        operation.1,
        origin,
        choices.keys().collect::<Vec<_>>()
    ])
    .to_string();
    if target.len() > options.result_bytes {
        return Err(fail());
    }
    let mut challenge = Challenge::new(target, options.result_bytes)?;
    let Some(index) = selected else {
        for names in choices.keys() {
            if work.is_cancelled() {
                return Err(InvocationError::cancelled());
            }
            let schema = if names.is_empty() {
                j!({"const":[]})
            } else {
                j!({"type":"array","items":{"enum":names},"uniqueItems":true,"minItems":names.len(),"maxItems":names.len()})
            };
            challenge.alternative(vec![j!({"type":"config.value","point":kind.security_point(),"path":"/schemes","schema":schema})])?;
        }
        return Err(challenge.finish()?);
    };
    input.selection.security = Some(index);
    let selected = &profile.security[index];
    if selected.is_empty() {
        return Ok(());
    }
    let credentials = member_object(root, "credentials")?;
    let keys = member_object(root, "apiKeys")?;
    let origins = member_object(point, "origins")?;
    let mut requirements = vec![];
    for (name, family) in selected {
        if work.is_cancelled() {
            return Err(InvocationError::cancelled());
        }
        let flat_name = match family {
            Family::Bearer => "bearerToken",
            Family::Key => "apiKey",
        };
        let flat = root.and_then(|r| r.get(flat_name));
        if flat.is_some() && selected.values().filter(|f| *f == family).count() != 1 {
            return Err(fail());
        }
        let material = consistent([
            credentials.and_then(|c| c.get(name)),
            if *family == Family::Key {
                keys.and_then(|k| k.get(name))
            } else {
                None
            },
            flat,
        ])?;
        let grant = origins
            .and_then(|o| o.get(name))
            .map(|v| {
                let mut result = vec![];
                for v in v.elements().ok_or_else(fail)? {
                    if work.is_cancelled() {
                        return Err(InvocationError::cancelled());
                    }
                    let raw = v.as_str().ok_or_else(fail)?;
                    // Validate all supplied grants; the client performs the final target check.
                    dynamic_openapi_client::uri::origin(raw).map_err(|_| fail())?;
                    result.push(raw.to_owned());
                }
                if result.is_empty()
                    || !result
                        .iter()
                        .any(|s| dynamic_openapi_client::uri::origin(s).is_ok_and(|o| o == origin))
                {
                    return Err(fail());
                }
                Ok(result)
            })
            .transpose()?;
        if material.is_none() {
            requirements.push(j!({"type":family.requirement(),"name":name}));
        }
        if grant.is_none() {
            requirements.push(j!({"type":"config.value","point":kind.security_point(),"path":format!("/origins/{}",name.replace('~',"~0").replace('/',"~1")),"schema":{"type":"array","minItems":1,"items":{"type":"string"},"description":format!("Caller-approved credential origins; selected destination is {origin}"),"examples":[[origin]]}}));
        }
        if let (Some(value), Some(origins)) = (material, grant) {
            let value = match family {
                Family::Bearer => CredentialValue::Bearer(value.into()),
                Family::Key => CredentialValue::ApiKey(value.into()),
            };
            input
                .credentials
                .insert(name.clone(), Credential { value, origins });
        }
    }
    if !requirements.is_empty() {
        challenge.alternative(requirements)?;
        return Err(challenge.finish()?);
    }
    Ok(())
}
fn member_object<'a>(
    parent: Option<JsonRef<'a>>,
    name: &str,
) -> Result<Option<JsonRef<'a>>, InvocationError> {
    let v = parent.and_then(|p| p.get(name));
    if v.is_some_and(|v| v.members().is_none()) {
        return Err(InvocationError::refused());
    }
    Ok(v)
}
fn consistent<'a>(values: [Option<JsonRef<'a>>; 3]) -> Result<Option<&'a str>, InvocationError> {
    let mut found = None;
    for v in values.into_iter().flatten() {
        let v = v.as_str().ok_or_else(InvocationError::refused)?;
        if found.is_some_and(|old| old != v) {
            return Err(InvocationError::refused());
        }
        found = Some(v);
    }
    Ok(found)
}
// Each fragment is charged before retaining it; total serialization is bounded
// again. All fragments originate in bounded source metadata, never secret values.
struct Challenge {
    target: String,
    alternatives: Vec<Value>,
    remaining: usize,
    limit: usize,
}
impl Challenge {
    fn new(target: String, limit: usize) -> Result<Self, InvocationError> {
        let size = j!({"target":target,"alternatives":[]}).to_string().len();
        Ok(Self {
            target,
            alternatives: vec![],
            remaining: limit
                .checked_sub(size)
                .ok_or_else(InvocationError::refused)?,
            limit,
        })
    }
    fn alternative(&mut self, requirements: Vec<Value>) -> Result<(), InvocationError> {
        let value = j!({"requirements":requirements});
        self.remaining = self
            .remaining
            .checked_sub(value.to_string().len() + 1)
            .ok_or_else(InvocationError::refused)?;
        self.alternatives.push(value);
        Ok(())
    }
    fn finish(self) -> Result<InvocationError, InvocationError> {
        let v = json(&j!({"target":self.target,"alternatives":self.alternatives}))
            .map_err(|_| InvocationError::refused())?;
        if v.bytes().len() > self.limit {
            return Err(InvocationError::refused());
        }
        ContextChallenge::new(v)
            .map(InvocationError::challenge)
            .map_err(|_| InvocationError::refused())
    }
}

impl Profile {
    fn retained_bytes(&self) -> usize {
        let servers = self
            .servers
            .iter()
            .fold(0usize, |n, s| n.saturating_add(s.len()).saturating_add(32));
        let servers = self.security.iter().fold(servers, |n, a| {
            a.keys().fold(n.saturating_add(64), |n, k| {
                n.saturating_add(k.len()).saturating_add(64)
            })
        });
        self.parameters.values().flat_map(|p| p.iter()).fold(
            servers.saturating_add(self.input_schema.bytes().len()),
            |n, (name, kind)| {
                n.saturating_add(name.len())
                    .saturating_add(kind.len())
                    .saturating_add(128)
            },
        )
    }
}

pub(crate) fn object(value: JsonRef<'_>, allowed: &[&str]) -> Result<(), Error> {
    let members = value
        .members()
        .ok_or_else(|| Error::new(ErrorKind::InvalidInput, "expected-object"))?;
    let mut names = HashSet::new();
    for member in members {
        let name = member
            .name
            .as_str()
            .ok_or_else(|| Error::new(ErrorKind::InvalidInput, "invalid-member-name"))?;
        if !allowed.contains(&name) || !names.insert(name) {
            return Err(Error::new(
                ErrorKind::InvalidInput,
                "unknown-or-duplicate-member",
            ));
        }
    }
    Ok(())
}
pub(crate) fn prepare(
    kind: Kind,
    content: &JsonValue,
    options: &Options,
    control: &WorkControl,
) -> Result<Prepared, Error> {
    object(content.view(), &["document", "retrievalUri"])?;
    let text = content
        .get("document")
        .and_then(JsonRef::as_str)
        .ok_or_else(|| Error::new(ErrorKind::InvalidInput, "document-text-required"))?;
    let input = match content.get("retrievalUri") {
        Some(v) => ResourceInput::at(
            v.as_str()
                .ok_or_else(|| Error::new(ErrorKind::InvalidInput, "retrieval-uri-required"))?,
            text.as_bytes(),
        )
        .map_err(|_| Error::new(ErrorKind::Unsupported, "retrieval-uri-unsupported"))?,
        None => ResourceInput::anonymous(text.as_bytes()),
    };
    let mut builder = DocumentBuilder::new(options.limits.clone(), options.graph_limits.clone());
    let entry = builder
        .add(input)
        .map_err(|_| Error::new(ErrorKind::InvalidInput, "document-admission"))?;
    for resource in &options.resources {
        check(control)?;
        builder
            .add(resource.clone())
            .map_err(|_| Error::new(ErrorKind::Unreadable, "resource-admission"))?;
    }
    let document = builder
        .build(entry)
        .map_err(|_| Error::new(ErrorKind::Unreadable, "graph-admission"))?;
    if document.format() != SourceFormat::Json || document.edition().ok() != Some(kind.edition()) {
        return Err(Error::new(
            ErrorKind::Unsupported,
            "unqualified-description",
        ));
    }
    let root = document.root();
    let mut exhaustive = document.discovery_complete()
        && root
            .get("paths")
            .is_none_or(|p| p.kind() == ValueKind::Object);
    let mut extra_interactions = root
        .get("webhooks")
        .is_some_and(|v| v.members().is_none_or(|mut m| m.next().is_some()));
    let mut remaining = options.result_bytes;
    let mut seen = HashSet::new();
    let mut units = Vec::new();
    for operation in document.operations() {
        check(control)?;
        let method = operation.method().as_str().to_ascii_lowercase();
        if !matches!(
            method.as_str(),
            "get" | "post" | "put" | "patch" | "delete" | "head" | "options" | "trace"
        ) || !operation.path().starts_with('/')
        {
            exhaustive = false;
            continue;
        }
        let item_pointer = format!(
            "/paths/{}",
            operation.path().replace('~', "~0").replace('/', "~1")
        );
        let established = document
            .protocol_at(
                &item_pointer,
                dynamic_openapi_client::ReferenceKind::PathItem,
            )
            .and_then(|site| document.resolve_protocol(&site));
        if let Ok(item) = &established
            && !item.chain.iter().any(|v| {
                v.get(&method)
                    .is_some_and(|v| v.kind() == ValueKind::Object)
            })
        {
            exhaustive = false;
            continue;
        }
        let ambiguous = established.as_ref().is_ok_and(|item| {
            [&*method, "parameters", "servers"]
                .iter()
                .any(|key| item.chain.iter().filter(|v| v.get(key).is_some()).count() > 1)
        });
        if !seen.insert((operation.path().to_owned(), method.clone())) {
            exhaustive = false;
            continue;
        }
        let source_ref = format!(
            "/paths/{}/{}",
            operation.path().replace('~', "~0").replace('/', "~1"),
            method
        );
        let binding = json(&serde_json_compat::json!({"path":operation.path(),"method":method}))?;
        extra_interactions |= operation
            .value()
            .get("callbacks")
            .is_some_and(|v| v.members().is_none_or(|mut m| m.next().is_some()));
        let profile = if ambiguous {
            Err("ambiguous-path-item-merge")
        } else {
            profile(&operation, kind)
        };
        let cost = source_ref
            .len()
            .saturating_add(binding.bytes().len())
            .saturating_add(profile.as_ref().map_or(0, Profile::retained_bytes))
            .saturating_add(512);
        remaining = remaining
            .checked_sub(cost)
            .ok_or_else(|| Error::new(ErrorKind::Limit, "result-limit"))?;
        units.push(Unit {
            operation,
            source_ref,
            binding,
            profile,
        });
    }
    check(control)?;
    Ok(Prepared {
        kind,
        content: content.clone(),
        document,
        units,
        exhaustive,
        extra_interactions,
    })
}
fn profile(operation: &Operation, kind: Kind) -> Result<Profile, &'static str> {
    if !operation.path().is_ascii() {
        return Err("literal-unicode-path-unimplemented");
    }
    if !matches!(operation.method(), Method::Get | Method::Post) {
        return Err("unqualified-method");
    }
    if operation
        .value()
        .get("callbacks")
        .is_some_and(|v| v.members().is_none_or(|mut m| m.next().is_some()))
    {
        return Err("callbacks-unimplemented");
    }
    let d = operation
        .describe()
        .map_err(|_| "operation-description-unavailable")?;
    let security = d
        .security
        .iter()
        .map(|a| {
            a.requirements
                .iter()
                .map(|r| {
                    use crate::security::Family;
                    use dynamic_openapi_client::SecurityScheme;
                    if !r.scopes.is_empty() {
                        return Err("security-roles-unimplemented");
                    }
                    let family = match &r.scheme {
                        SecurityScheme::Bearer { .. } => Family::Bearer,
                        SecurityScheme::ApiKey {
                            location: ParameterLocation::Header,
                            ..
                        } => Family::Key,
                        _ => return Err("security-unimplemented"),
                    };
                    Ok((r.name.clone(), family))
                })
                .collect::<Result<crate::security::Alternative, _>>()
        })
        .collect::<Result<Vec<_>, _>>()?;
    if d.servers.is_empty()
        || d.servers.iter().any(|s| {
            s.variables
                .as_ref()
                .is_some_and(|v| v.members().is_none_or(|mut m| m.next().is_some()))
                || dynamic_openapi_client::uri::origin(&s.url).is_err()
                || s.url.contains('?')
        })
    {
        return Err("server-profile-unimplemented");
    }
    let mut locations =
        BTreeMap::<&str, serde_json_compat::Map<String, serde_json_compat::Value>>::from([
            ("path", Default::default()),
            ("query", Default::default()),
        ]);
    let mut required = BTreeMap::<&str, Vec<String>>::new();
    let mut schema_loss = false;
    let mut parameters: BTreeMap<&'static str, BTreeMap<String, String>> = BTreeMap::new();
    for param in d.parameters.iter() {
        let location = match param.location() {
            ParameterLocation::Path => "path",
            ParameterLocation::Query => "query",
            _ => return Err("parameter-location-unimplemented"),
        };
        let raw = param.resolved().target;
        let expected_style = if location == "path" { "simple" } else { "form" };
        if raw.get("content").is_some()
            || raw
                .get("style")
                .is_some_and(|v| v.as_str() != Some(expected_style))
        {
            return Err("parameter-representation-unimplemented");
        }
        let description = param
            .schema_description()
            .ok_or("parameter-shape-unestablished")?;
        if kind == Kind::OpenApi31
            && !matches!(&description.profile, SchemaProfile::JsonSchema { dialect_uri }
                if matches!(dialect_uri.as_str(),
                    "https://spec.openapis.org/oas/3.1/dialect/base"
                    | "https://spec.openapis.org/oas/3.1/dialect/2024-11-10"
                    | "https://json-schema.org/draft/2020-12/schema"))
        {
            // Use the client's lexical context, including schema-level overrides.
            // Other dialects may ignore or reinterpret the apparent type keyword.
            return Err("parameter-schema-dialect-unimplemented");
        }
        let schema = description.value;
        if kind == Kind::OpenApi30 {
            // A 3.0 Schema Reference Object's siblings do not establish a type.
            // Resolving/translating schema contracts remains outside this profile.
            if schema.get("$ref").is_some() {
                return Err("parameter-schema-reference-unimplemented");
            }
            // This experiment has no caller-to-wire mapping for null parameters.
            // Refuse the profile rather than synthesize a narrower claimed contract.
            if schema
                .get("nullable")
                .is_some_and(|v| v.as_bool() != Some(false))
            {
                return Err("nullable-parameter-unimplemented");
            }
        }
        let kind = schema
            .get("type")
            .and_then(|v| v.as_str().map(str::to_owned))
            .ok_or("parameter-shape-unestablished")?;
        if !matches!(kind.as_str(), "string" | "integer" | "number" | "boolean") {
            return Err("parameter-shape-unimplemented");
        }
        parameters
            .entry(location)
            .or_default()
            .insert(param.name().into(), kind.clone());
        locations
            .entry(location)
            .or_default()
            .insert(param.name().into(), serde_json_compat::json!({"type":kind}));
        if param.required() {
            required
                .entry(location)
                .or_default()
                .push(param.name().into());
        }
        schema_loss |= schema
            .members()
            .is_none_or(|mut m| m.any(|(k, _)| k != "type"));
    }
    if let Some(body) = &d.request_body {
        if body.media_unrestricted
            || body.media.len() != 1
            || body.media[0].media_type != "application/json"
        {
            return Err("request-media-unimplemented");
        }
        if body.media[0].encoding.is_some() {
            return Err("request-encoding-unimplemented");
        }
        schema_loss |= body.media[0].schema.is_some();
    }
    for response in &d.responses {
        if !response.status.starts_with('2') && response.status != "default" {
            schema_loss |=
                !response.media.is_empty() || response.declaration.target.get("headers").is_some();
            continue;
        }
        if response.media.is_empty() && response.status != "204" {
            return Err("response-no-content-unimplemented");
        }
        if response
            .media
            .iter()
            .any(|m| m.media_type != "application/json")
        {
            return Err("response-media-unimplemented");
        }
        if response
            .declaration
            .target
            .get("headers")
            .is_some_and(|v| v.members().is_none_or(|mut m| m.next().is_some()))
        {
            return Err("response-headers-unimplemented");
        }
        schema_loss |= response.media.iter().any(|m| m.schema.is_some());
    }
    let mut parameter_properties = serde_json_compat::Map::new();
    let mut required_locations = Vec::new();
    for (location, props) in locations {
        let needed = required.remove(location).unwrap_or_default();
        if !needed.is_empty() {
            required_locations.push(location);
        }
        parameter_properties.insert(location.into(), serde_json_compat::json!({"type":"object","properties":props,"required":needed,"additionalProperties":false}));
    }
    let mut properties = serde_json_compat::Map::new();
    let mut required_fields = Vec::new();
    if !parameter_properties.is_empty() {
        if !required_locations.is_empty() {
            required_fields.push("parameters");
        }
        properties.insert("parameters".into(), serde_json_compat::json!({"type":"object","properties":parameter_properties,"required":required_locations,"additionalProperties":false}));
    }
    if let Some(body) = &d.request_body {
        properties.insert("body".into(), serde_json_compat::Value::Bool(true));
        if body.required {
            required_fields.push("body");
        }
    }
    let input_schema = json(&serde_json_compat::json!({"type":"object","properties":properties,"required":required_fields,"additionalProperties":false})).map_err(|_| "schema-budget")?;
    Ok(Profile {
        security,
        has_body: d.request_body.is_some(),
        servers: d.servers.into_iter().map(|s| s.url).collect(),
        parameters,
        input_schema,
        schema_loss,
    })
}

/// Application-owned execution of one prepared request. Implementations must
/// report honest client outcome evidence and own cancellation/cleanup. No executor
/// or Send bound is imposed. A closure taking an owned plan can implement this.
pub trait Transport {
    /// A host future that may borrow its reusable host.
    type Execution<'a>: Future<Output = Outcome>
    where
        Self: 'a;
    /// Execute once; ownership of the plan avoids self-referential futures.
    fn execute(&self, request: PreparedRequest, cancellation: Cancellation) -> Self::Execution<'_>;
}
impl<F, Fut> Transport for F
where
    F: Fn(PreparedRequest, Cancellation) -> Fut,
    Fut: Future<Output = Outcome>,
{
    type Execution<'a>
        = Fut
    where
        Self: 'a;
    fn execute(&self, request: PreparedRequest, cancellation: Cancellation) -> Fut {
        self(request, cancellation)
    }
}

type NextInput = Pin<Box<dyn Future<Output = (ProviderInput, Option<JsonValue>)> + Send>>;
type Emit = Pin<Box<dyn Future<Output = Result<(), InvocationError>> + Send>>;
fn receive(mut input: ProviderInput) -> NextInput {
    Box::pin(async move {
        let value = input.next().await;
        (input, value)
    })
}
fn emit(mut output: ProviderOutput, value: JsonValue) -> Emit {
    Box::pin(async move { output.emit(value).await })
}

/// Provider job preserving conditional Send: a local host stays local; a Sync
/// host with Send execution futures can be used by native multithreaded callers.
/// Dropping it cancels its client token and drops pending host work.
pub struct InvocationFuture<'a, T: Transport> {
    provider: &'a OpenApi<T>,
    request: BindingRequest<'a>,
    input: Option<NextInput>,
    value: Option<JsonValue>,
    output: Option<ProviderOutput>,
    execution: Option<Pin<Box<T::Execution<'a>>>>,
    emitting: Option<Emit>,
    control: openbindings::Cancellation,
    cancellation: Cancellation,
    work: WorkControl,
    done: bool,
}
impl<T: Transport> Unpin for InvocationFuture<'_, T> {}
impl<T: Transport> Drop for InvocationFuture<'_, T> {
    fn drop(&mut self) {
        self.cancellation.cancel();
    }
}
impl<T: Transport> Future for InvocationFuture<'_, T> {
    type Output = Result<(), InvocationError>;
    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Self::Output> {
        let this = self.get_mut();
        assert!(!this.done, "polled completed adapter job");
        let result = loop {
            if Pin::new(&mut this.control).poll(cx).is_ready() {
                this.cancellation.cancel();
                break Poll::Ready(Err(InvocationError::cancelled()));
            }
            if let Some(input) = &mut this.input {
                let (input, value) = match input.as_mut().poll(cx) {
                    Poll::Pending => return Poll::Pending,
                    Poll::Ready(value) => value,
                };
                this.input = None;
                if let Some(value) = value {
                    if this.value.is_some() {
                        break Poll::Ready(Err(InvocationError::refused()));
                    }
                    this.value = Some(value);
                    this.input = Some(receive(input));
                    continue;
                }
                drop(input);
                let Some(value) = this.value.take() else {
                    break Poll::Ready(Err(InvocationError::refused()));
                };
                let prepared =
                    match prepare_request(this.provider, this.request, &value, &this.work) {
                        Ok(p) => p,
                        Err(e) => break Poll::Ready(Err(e)),
                    };
                if this.work.is_cancelled() {
                    break Poll::Ready(Err(InvocationError::cancelled()));
                }
                this.execution = Some(Box::pin(
                    this.provider
                        .transport
                        .execute(prepared, this.cancellation.clone()),
                ));
            }
            if let Some(execution) = &mut this.execution {
                let outcome = match execution.as_mut().poll(cx) {
                    Poll::Pending => return Poll::Pending,
                    Poll::Ready(outcome) => outcome,
                };
                this.execution = None;
                let kind =
                    Kind::from_label(&this.request.source.kind).expect("admitted source kind");
                let value = match accept(outcome, kind) {
                    Ok(value) => value,
                    Err(e) => break Poll::Ready(Err(e)),
                };
                if let Some(value) = value {
                    this.emitting =
                        Some(emit(this.output.take().expect("one output owner"), value));
                } else {
                    break Poll::Ready(Ok(()));
                }
            }
            if let Some(emitting) = &mut this.emitting {
                break emitting.as_mut().poll(cx);
            }
        };
        if result.is_ready() {
            this.done = true;
        }
        result
    }
}
impl<T: Transport> BindingInvoker for OpenApi<T> {
    type Invocation<'a>

        Self: 'a;
    fn supports_kind(&self, kind: &str) -> bool {

    }
    fn supported_kinds(&self) -> Vec<SupportedKind> {
        Kind::ALL

            .map(|kind| SupportedKind {

                description: Some(
                    "Private finite JSON experiment; no implicit retry or resource acquisition"

    }
    fn invoke<'a>(

}
fn prepare_request<T>(
    provider: &OpenApi<T>,
    request: BindingRequest<'_>,
    value: &JsonValue,
    control: &WorkControl,
) -> Result<PreparedRequest, InvocationError> {
    let refused = || InvocationError::refused();
    let p = provider.prepare(request.source, control).map_err(|_| {
        if control.is_cancelled() {
            InvocationError::cancelled()
        } else {
            refused()
        }
    })?;
    let binding = request.binding.content.as_ref().ok_or_else(refused)?;
    analysis::object(binding.view(), &["path", "method"]).map_err(|_| refused())?;
    let path = binding
        .get("path")
        .and_then(JsonRef::as_str)
        .ok_or_else(refused)?;
    let method = binding
        .get("method")
        .and_then(JsonRef::as_str)
        .ok_or_else(refused)?;
    let unit = p
        .units
        .iter()
        .find(|u| {
            u.operation.path() == path && u.operation.method().as_str().eq_ignore_ascii_case(method)
        })
        .ok_or_else(refused)?;
    if method != method.to_ascii_lowercase() {
        return Err(refused());
    }
    let profile = unit.profile.as_ref().map_err(|_| refused())?;
    analysis::object(value.view(), &["parameters", "body"]).map_err(|_| refused())?;
    if value.has_duplicate_names() {
        return Err(refused());
    }
    let mut input = Input::default();
    if let Some(parameters) = value.get("parameters") {
        analysis::object(parameters, &["path", "query"]).map_err(|_| refused())?;
        let supplied = ["path", "query"]
            .into_iter()
            .filter_map(|name| parameters.get(name))
            .try_fold(0usize, |n, value| {
                let mut total = n;
                for _ in value.members().ok_or_else(refused)? {
                    if control.is_cancelled() {
                        return Err(InvocationError::cancelled());
                    }
                    total = total.checked_add(1).ok_or_else(refused)?;
                    if total > provider.options.limits.reference_steps {
                        return Err(refused());
                    }
                }
                Ok(total)
            })?;
        input.parameters.reserve(supplied);
        for (location, location_name) in [
            (ParameterLocation::Path, "path"),
            (ParameterLocation::Query, "query"),
        ] {
            if let Some(values) = parameters.get(location_name) {
                let members = values.members().ok_or_else(refused)?;
                let mut names = std::collections::HashSet::new();
                for member in members {
                    let name = member.name.as_str().ok_or_else(refused)?;
                    if !names.insert(name) {
                        return Err(refused());
                    }
                    if control.is_cancelled() {
                        return Err(InvocationError::cancelled());
                    }
                    let expected = profile
                        .parameters
                        .get(location_name)
                        .and_then(|parameters| parameters.get(name))
                        .ok_or_else(refused)?;
                    let valid = match member.value.kind() {
                        JsonKind::String => expected == "string",
                        JsonKind::Boolean => expected == "boolean",
                        JsonKind::Number => {
                            expected == "number"
                                || (expected == "integer"
                                    && integer(member.value.number_text().expect("number")))
                        }
                        _ => false,
                    };
                    if !valid {
                        return Err(refused());
                    }
                    let value =
                        ExactJson::parse(member.value.text(), provider.options.limits.clone())
                            .map_err(|_| refused())?
                            .root();
                    input.parameters.push(ParameterInput {
                        location,
                        name: name.into(),
                        value,
                    });
                }
            }
        }
    }
    if let Some(body) = value.get("body") {
        if !profile.has_body {
            return Err(refused());
        }
        input.body = Body::Json(
            ExactJson::parse(body.text(), provider.options.limits.clone())
                .map_err(|_| refused())?
                .root(),
        );
    }
    let servers = &profile.servers;
    let server_point = p.kind.server_point();
    let choice = request
        .context
        .and_then(|c| c.get("configuration"))
        .and_then(|c| c.get(server_point));
    let selected = match choice {
        Some(choice) => choice
            .as_str()
            .and_then(|s| servers.iter().position(|candidate| candidate == s)),
        None if servers.iter().all(|s| s == &servers[0]) => Some(0),
        None => None,
    };
    input.selection.server = Some(selected.ok_or_else(|| {
        let choices: std::collections::BTreeSet<_> = servers.iter().map(|s| s.as_str()).collect();
        let target = serde_json_compat::json!([p.kind.label(), request.source.content.as_ref().and_then(|v| v.get("retrievalUri")).and_then(JsonRef::as_str), path, method, choices]).to_string();
        let shape = json(&serde_json_compat::json!({"target":target,"alternatives":[{"requirements":[{"type":"config.value","point":server_point,"path":"","schema":{"type":"string","enum":choices}}]}]}));
        shape.ok().and_then(|v| ContextChallenge::new(v).ok()).map(InvocationError::challenge).unwrap_or_else(refused)
    })?);
    crate::security::apply(
        profile,
        p.kind,
        request.context,
        &servers[input.selection.server.expect("selected")],
        (path, method),
        &provider.options,
        control,
        &mut input,
    )?;
    unit.operation.prepare(&input).map_err(|_| refused())
}
fn accept(outcome: Outcome, kind: Kind) -> Result<Option<JsonValue>, InvocationError> {
    if outcome.cancelled {
        return Err(InvocationError::cancelled());
    }
    // A host outcome is evidence, not permission to infer absence of effects.
    if outcome.error.is_some()
        || outcome.dispatch != dynamic_openapi_client::DispatchEvidence::Dispatched
    {
        return Err(InvocationError::execution_failed());
    }
    let response = outcome
        .response
        .ok_or_else(InvocationError::execution_failed)?;
    if response.body_state() != BodyState::Complete
        || response.header_delivery() != HeaderDelivery::Complete
        || response.omitted_header_lines() != 0
    {
        return Err(InvocationError::execution_failed());
    }
    if !(200..300).contains(&response.status()) {
        let data = json(&serde_json_compat::json!({"status":response.status()}))
            .map_err(|_| InvocationError::execution_failed())?;
        return Err(InvocationError::new(kind.status_error(), Some(data))
            .expect("fixed governed error shape"));
    }
    if response.status() == 204 {
        return if response.raw().is_empty() {
            Ok(None)
        } else {
            Err(InvocationError::execution_failed())
        };
    }
    let decoded = response
        .json()
        .map_err(|_| InvocationError::execution_failed())?;
    JsonValue::parse(decoded.source())
        .map(Some)
        .map_err(|_| InvocationError::execution_failed())
}

// Exact integrality without machine-number conversion or exponent expansion.
fn integer(token: &str) -> bool {
    let token = token.trim_start_matches('-');
    let (mantissa, exponent) = token.split_once(['e', 'E']).unwrap_or((token, "0"));
    if mantissa.bytes().all(|b| b == b'0' || b == b'.') {
        return true;
    }
    let fractional = mantissa.split_once('.').map_or(0, |(_, f)| f.len());
    let zeros = mantissa
        .bytes()
        .filter(|b| *b != b'.')
        .rev()
        .take_while(|b| *b == b'0')
        .count();
    let exponent = exponent
        .parse::<i64>()
        .unwrap_or(if exponent.starts_with('-') {
            i64::MIN
        } else {
            i64::MAX
        });
    exponent >= fractional as i64 - zeros as i64
}

impl Error {

            ErrorKind::InvalidInput => SynthesisErrorKind::InvalidInput,
            ErrorKind::Unsupported => SynthesisErrorKind::UnsupportedRequest,

            ErrorKind::Cancelled => SynthesisErrorKind::Cancelled,

            format!("openbindings.openapi.{}", self.code()),

impl<T> OpenApi<T> {
    fn derive(
        &self,
        request: &SynthesisRequest<'_>,
        control: &WorkControl,
    ) -> Result<SynthesisCandidate, SynthesisError> {
        check(control).map_err(|e| e.synthesis())?;
        if request.sources.len() > 1 {
            return Err(SynthesisError::new(
                SynthesisErrorKind::UnsupportedRequest,
                "openbindings.openapi.composition-unimplemented",
                "This experiment accepts at most one supplied source",
            ));
        }
        let mut draft = DocumentBuilder::new();
        if let Some(version) = request.openbindings_version {
            draft.openbindings = version.into();
        }
        draft.name = request.name.map(str::to_owned);
        draft.version = request.version.map(str::to_owned);
        draft.description = request.description.map(str::to_owned);
        let mut coverage = CoverageDraft {
            exhaustive: true,
            ..Default::default()
        };
        if let Some(input) = request.sources.first() {
            let prepared = self
                .prepare(input.source, control)
                .map_err(|e| e.synthesis())?;
            let source_key = input.name.unwrap_or("api").to_owned();
            draft.sources = Some(BTreeMap::from([(source_key.clone(), input.source.clone())]));
            let mut bindings = BTreeMap::new();
            for (index, unit) in prepared.units.iter().enumerate() {
                check(control).map_err(|e| e.synthesis())?;
                let mut entry = CoverageEntry::new(
                    0,
                    &unit.source_ref,
                    CoverageScope::Target,
                    CoverageStatus::Represented,
                );
                match &unit.profile {
                    Ok(profile) => {
                        // Core keys have an ASCII grammar. The ordinal guarantees
                        // uniqueness; the short path hint is authoring convenience.
                        let hint: String = unit
                            .operation
                            .path()
                            .chars()
                            .take(48)
                            .map(|c| if c.is_ascii_alphanumeric() { c } else { '_' })
                            .collect();
                        let key = format!(
                            "{}_{}_{}",
                            unit.operation.method().as_str().to_ascii_lowercase(),
                            index + 1,
                            hint
                        );
                        draft.operations.insert(
                            key.clone(),
                            Operation {
                                input: Some(profile.input_schema.clone()),
                                ..Default::default()
                            },
                        );
                        bindings.insert(
                            key.clone(),
                            Binding {
                                operation: key.clone(),
                                source: source_key.clone(),
                                content: Some(unit.binding.clone()),
                                ..Default::default()
                            },
                        );
                        entry.source_key = Some(source_key.clone());
                        entry.operation_key = Some(key.clone());
                        entry.binding_key = Some(key.clone());
                        if profile.security.iter().any(|a| !a.is_empty()) {
                            entry.requirements=Some(vec!["Per-attempt security selection, named credentials and caller-approved origins as applicable".into()]);
                            entry.details = Some(BTreeMap::from([(
                                "security".into(),
                                crate::json(&crate::security::details(profile))
                                    .map_err(|e| e.synthesis())?,
                            )]));
                        }
                        coverage.entries.push(entry);
                        if profile.schema_loss {
                            let mut loss = CoverageEntry::new(
                                0,
                                &unit.source_ref,
                                CoverageScope::Projection,
                                CoverageStatus::Lossy,
                            );
                            loss.source_key = Some(source_key.clone());
                            loss.operation_key = Some(key.clone());
                            loss.binding_key = Some(key);
                            loss.reason_code =
                                Some("openbindings.openapi.schema-contract-not-projected".into());
                            loss.message=Some("The input schema describes the adapter envelope; source value constraints and response schemas are not fully projected".into());
                            coverage.entries.push(loss);
                        }
                    }
                    Err(reason) => {
                        entry.status = CoverageStatus::ImplementationUnsupported;
                        entry.reason_code = Some(format!("openbindings.openapi.{reason}"));
                        entry.message=Some("This implementation cannot faithfully represent the declared operation profile; the target is not declared invalid or excluded by a kind rule".into());
                        coverage.entries.push(entry);
                    }
                }
            }
            if !bindings.is_empty() {
                draft.bindings = Some(bindings);
            }
            coverage.exhaustive = prepared.exhaustive && !prepared.extra_interactions;
            if !coverage.exhaustive {
                let resources: Vec<_> = prepared
                    .document
                    .graph_issues()
                    .filter_map(|d| {
                        d.resource_need()
                            .and_then(|r| r.requested_uri())
                            .map(str::to_owned)
                    })
                    .collect();
                let details =
                    crate::json(&serde_json_compat::json!({"requiredResources":resources}))
                        .map_err(|e| e.synthesis())?;
                coverage.limitation=Some(CoverageLimitation{code:"openbindings.openapi.inventory-incomplete".into(),message:"The supplied resources and implemented interaction profile do not establish every source unit; no empty/full inventory claim is made".into(),details:Some(BTreeMap::from([("inventory".into(),details)])),additional_fields:BTreeMap::new()});
            }
        }
        check(control).map_err(|e| e.synthesis())?;
        let document = ParsedDocument::from_json(draft.to_json()?);
        if document.value().bytes().len()
            > self
                .options
                .source_bytes
                .saturating_add(self.options.result_bytes)
        {
            return Err(Error::new(ErrorKind::Limit, "synthesis-result-limit").synthesis());
        }
        Ok(SynthesisCandidate { document, coverage })
    }
}

/// Fixed resources and finite admission budgets. Changing these requires a new provider.

/// Reusable adapter. Inspection and synthesis need no transport; bind one once
/// with [`Self::with_transport`] to enable the existing BindingInvoker role.

pub struct OpenApi<T = ()> {

    preparations: std::sync::atomic::AtomicUsize,
}
impl Default for OpenApi<()> {
    fn default() -> Self {
        Self {
            options: Options::default(),
            transport: (),
            cached: Mutex::new(None),
            #[cfg(test)]
            preparations: std::sync::atomic::AtomicUsize::new(0),
        }
    }
}
impl OpenApi<()> {
    /// Check a fixed supplied-resource collection without performing I/O.
    pub fn new(options: Options) -> Result<Self, Error> {
        let mut builder =
            DocumentBuilder::new(options.limits.clone(), options.graph_limits.clone());
        for resource in &options.resources {
            builder
                .add(resource.clone())
                .map_err(|_| Error::new(ErrorKind::InvalidInput, "resource-admission"))?;
        }
        Ok(Self {
            options,
            ..Self::default()
        })
    }
}
impl<T> OpenApi<T> {
    /// Bind application-owned HTTP execution. Native and local non-Send hosts are supported.
    pub fn with_transport<H: Transport>(self, transport: H) -> OpenApi<H> {
        OpenApi {
            options: self.options,
            transport,
            cached: self.cached,
            #[cfg(test)]
            preparations: self.preparations,
        }
    }
    fn prepare(
        &self,
        source: &Source,
        control: &WorkControl,
    ) -> Result<Arc<analysis::Prepared>, Error> {
        check(control)?;
        let kind = Kind::from_label(&source.kind)
            .ok_or_else(|| Error::new(ErrorKind::Unsupported, "unsupported-kind"))?;
        let content = source
            .content
            .as_ref()
            .ok_or_else(|| Error::new(ErrorKind::InvalidInput, "missing-source-content"))?;
        if content.bytes().len() > self.options.source_bytes {
            return Err(Error::new(ErrorKind::Limit, "source-limit"));
        }
        let mut cache = self
            .cached
            .lock()
            .map_err(|_| Error::new(ErrorKind::Unreadable, "poisoned-cache"))?;
        check(control)?;
        if let Some(prepared) = cache.as_ref().filter(|p| {
            p.kind == kind
                && (std::ptr::eq(p.content.text(), content.text())
                    || p.content.text() == content.text())
        }) {
            return Ok(prepared.clone());
        }
        *cache = None;
        let prepared = Arc::new(analysis::prepare(kind, content, &self.options, control)?);
        #[cfg(test)]
        self.preparations
            .fetch_add(1, std::sync::atomic::Ordering::Relaxed);
        *cache = Some(prepared.clone());
        Ok(prepared)
    }
}

#[derive(Default)]
pub struct Seen {pub calls:Cell<usize>,pub wires:RefCell<Vec<Value>>}
pub fn host(seen:Rc<Seen>,status:u16,body:&str)->impl Fn(PreparedRequest,Cancellation)->std::pin::Pin<Box<dyn Future<Output=Outcome>>>{
    let body=body.to_owned();
    move |request,cancel| { let seen=seen.clone();let body=body.clone();Box::pin(async move {
        // Count adapter-to-host entry too, including a client-side dispatch refusal.
        seen.calls.set(seen.calls.get()+1);
        request.invoke(cancel,&HostCapabilities::programmable(),move |wire,_|async move{
            seen.wires.borrow_mut().push(json!({"target":wire.target,"headers":wire.headers.iter().map(|h|(h.name().to_lowercase(),String::from_utf8(h.value().to_vec()).unwrap())).collect::<Vec<_>>(),"body":wire.body.as_deref().map(|b|String::from_utf8(b.to_vec()).unwrap())}));
            let mut response=ResponseInput::new(status,vec![Header::new("content-type","application/json")],DeliveredBody{bytes:Arc::from(body.as_bytes()),state:BodyState::Complete,provenance:Provenance::Wire});response.header_delivery=HeaderDelivery::Complete;
            TransportResult{upload:UploadState::Complete,response:Some(response),error_detail:None}
        }).await
    })}
}
pub async fn binding_call<P:binding::BindingInvoker>(p:P,src:&Source,path:&str,method:&str,context:Option<&JsonValue>,inputs:&[&str])->Result<Vec<String>,InvocationError>{
    let b=BindingValue{content:Some(value(json!({"path":path,"method":method}))),..Default::default()};
    let invoker=binding::Invoker::new(p);let mut call=invoker.invoke(BindingRequest{source:src,binding:&b,context});
    for v in inputs {let _=call.write(JsonValue::parse(v).unwrap()).await;}call.close();drain(&mut call).await
}
async fn drain<F:Future<Output=Result<(),InvocationError>>>(call:&mut openbindings_invocation::Invocation<F>)->Result<Vec<String>,InvocationError>{
    let mut out=vec![];while let Some(v)=call.next().await {match v{Ok(v)=>out.push(v.text().into()),Err(e)=>{assert!(out.is_empty());return Err(e);}}}
    call.outcome().expect("terminal")?;Ok(out)
}
pub async fn operation_call<P:binding::BindingInvoker>(p:P,saved:&str,key:&str,context:&JsonValue,input:&str)->Result<Vec<String>,InvocationError>{
    let invoker=operation::Invoker::new(ParsedDocument::parse(saved).unwrap(),p).with_evaluator(Arc::new(openbindings_json_schema_evaluator::DefaultEvaluator::new()),openbindings::ResourceSet::default()).unwrap();
    let mut call=invoker.invoke(operation::Request::operation(key).with_context(context));let _=call.write(JsonValue::parse(input).unwrap()).await;call.close();drain(&mut call).await
}
fn assert_wire(seen:&Seen,row:&Value){
    assert_eq!(seen.calls.get(),1);let wires=seen.wires.borrow();assert_eq!(wires.len(),1);let w=&wires[0];
    assert_eq!(w["target"],format!("https://api.example.test{}",row["path"].as_str().unwrap()));assert_eq!(w["body"],row["bodyText"]);
    let h=w["headers"].as_array().unwrap();
    for name in ["authorization","x-partner-key","x-second-key"] {
        let matches:Vec<_>=h.iter().filter(|x|x[0]==name).collect();
        let expected=row["authHeaders"].as_object().unwrap().iter().find(|(n,_)|n.eq_ignore_ascii_case(name)).map(|(_,v)|v);
        assert_eq!(matches.len(),usize::from(expected.is_some()));if let Some(expected)=expected {assert_eq!(&matches[0][1],expected);}
    }
}

/// Repeated resource/effect mix including a pending host and independent sibling.
pub async fn cycle(v30:bool){
    use openbindings::WorkControl;
    use std::task::Poll;
    let (kind,text,_,_)=edition(v30);let src=source(kind,text);let good=value(context(kind,&["ServiceToken"]));
    for (ctx,status,body,code,effects) in [(Some(&good),200,OUTPUT,None,1),(None,200,OUTPUT,Some("CONTEXT_REQUIRED"),0),(Some(&good),401,OUTPUT,Some(if v30{openbindings_openapi::HTTP_STATUS_ERROR_30}else{openbindings_openapi::HTTP_STATUS_ERROR}),1),(Some(&good),200,"{",Some("ERR_EXECUTION_FAILED"),1)]{
        let seen=Rc::new(Seen::default());let p=OpenApi::default().with_transport(host(seen.clone(),status,body));let r=binding_call(p,&src,"/items","get",ctx,&["{}"]).await;
        match code{None=>assert_eq!(r.unwrap(),[OUTPUT]),Some(code)=>assert_eq!(r.unwrap_err().code(),code)}assert_eq!(seen.calls.get(),effects);
    }
    let mut wrong=context(kind,&["ServiceToken"]);wrong["configuration"][format!("{kind}.security")]["origins"]["ServiceToken"]=json!(["https://wrong.test"]);let seen=Rc::new(Seen::default());assert_eq!(binding_call(OpenApi::default().with_transport(host(seen.clone(),200,OUTPUT)),&src,"/items","get",Some(&value(wrong)),&["{}"]).await.unwrap_err().code(),"ERR_REFUSED");assert_eq!(seen.calls.get(),0);
    struct Guard(Rc<Cell<usize>>);impl Drop for Guard{fn drop(&mut self){self.0.set(self.0.get()-1);}}
    for abandon in [false,true]{
        let live=Rc::new(Cell::new(0));let effects=Rc::new(Cell::new(0));let count=effects.clone();let registered=live.clone();
        let p=OpenApi::default().with_transport(move |request:PreparedRequest,cancel:Cancellation|{let registered=registered.clone();let count=count.clone();async move{
            count.set(count.get()+1);
            let pending=request.headers().iter().any(|h|h.value()==b"Bearer fixture-bearer-A");
            if pending {registered.set(registered.get()+1);let _guard=Guard(registered);std::future::pending::<Outcome>().await}
            else {request.invoke(cancel,&HostCapabilities::programmable(),|_,_|async {let mut response=ResponseInput::new(200,vec![Header::new("content-type","application/json")],DeliveredBody{bytes:Arc::from(OUTPUT.as_bytes()),state:BodyState::Complete,provenance:Provenance::Wire});response.header_delivery=HeaderDelivery::Complete;TransportResult{upload:UploadState::Complete,response:Some(response),error_detail:None}}).await}
        }});
        let invoker=binding::Invoker::new(&p);let b=BindingValue{content:Some(value(json!({"path":"/items","method":"get"}))),..Default::default()};let control=WorkControl::new();
        let mut job=invoker.invoke_with_control(BindingRequest{source:&src,binding:&b,context:Some(&good)},&control);job.write(JsonValue::parse("{}").unwrap()).await.unwrap();job.close();
        {let mut next=std::pin::pin!(job.next());std::future::poll_fn(|cx|{assert!(next.as_mut().poll(cx).is_pending());Poll::Ready(())}).await;}
        assert_eq!(live.get(),1);assert_eq!(effects.get(),1);
        let mut sibling=context(kind,&["ServiceToken"]);sibling["credentials"]["ServiceToken"]=json!("fixture-bearer-B");assert!(binding_call(&p,&src,"/items","get",Some(&value(sibling)),&["{}"]).await.is_ok());assert_eq!(live.get(),1);assert_eq!(effects.get(),2);
        if !abandon{control.cancel();assert_eq!(job.next().await.unwrap().unwrap_err().code(),"ERR_CANCELLED");}drop(job);assert_eq!(live.get(),0);
        let cancelled=WorkControl::new();cancelled.cancel();let mut before=invoker.invoke_with_control(BindingRequest{source:&src,binding:&b,context:Some(&good)},&cancelled);before.close();assert_eq!(before.next().await.unwrap().unwrap_err().code(),"ERR_CANCELLED");assert_eq!(effects.get(),2);
    }
}
