This draft uses inputSchema where the operation member is input. Check its diagnostics, then correct the original source and prepare the input contract. Checks run in an owned Worker; only the latest edit renders. Changes are local to this page.

Locations refer to the original JSON: lines and UTF-8 byte columns start at one; byte offsets start at zero. These are not JavaScript UTF-16 selection offsets. Go to first issue converts the original byte offset to a textarea cursor position. Pointers are JSON-quoted, making newlines, tabs, quotes and backslashes visible; other Unicode formatting characters are not escaped.
