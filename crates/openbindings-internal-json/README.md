# openbindings-internal-json

This package is an implementation detail. Rust callers should use the exact JSON types re-exported by `openbindings`. It is separately archived because public packages depend on it; it is not a supported extension API.

Version 0.2.0-alpha.1 is an unpublished development build. It requires Rust 1.99.
The full repository includes public caller examples, capabilities, release process,
license inventory and verification instructions. Package publication and application
cutover are separate actions.
